# موقع SphinxPack — دليل التشغيل

موقع لبيع مستلزمات التغليف (أكواب، علب وجبات، فويل، أدوات مائدة، إكسسوارات، مستلزمات طبية) مع:
- سلة طلبات وإرسال الطلب عبر واتساب لرقم **01028735709**.
- لوحة تحكم أدمن (`admin.html`) لإدارة المنتجات والأوردرات، بكلمة مرور، ومسح باركود بالكاميرا، وتنبيه صوتي عند وصول أوردر جديد.
- تخزين البيانات على **Firebase Realtime Database** (مجاني في الحدود العادية للاستخدام الصغير والمتوسط).

---

## 1) إنشاء مشروع Firebase (خطوة أولى وأهم خطوة)

1. ادخل على **console.firebase.google.com** وسجل الدخول بحساب Google.
2. اضغط **Add project / إضافة مشروع** واسمه مثلاً `sphinxpack`.
3. من القائمة الجانبية: **Build → Realtime Database → Create Database**.
   - اختر أي موقع سيرفر قريب (مثلاً `europe-west1`).
   - ابدأ في **وضع الاختبار (test mode)** مؤقتًا، وبعدين هنظبط الصلاحيات (خطوة 4).
4. من نفس الصفحة، اضغط على أيقونة الويب `</>` لإضافة تطبيق ويب:
   - اديله اسم `sphinxpack-web` واضغط تسجيل.
   - هيديك كائن `firebaseConfig` فيه قيم زي:
     ```js
     const firebaseConfig = {
       apiKey: "...",
       authDomain: "...",
       databaseURL: "...",
       projectId: "...",
       storageBucket: "...",
       messagingSenderId: "...",
       appId: "..."
     };
     ```
5. افتح ملف **`assets/firebase-init.js`** في المشروع، واستبدل القيم الموجودة بالقيم اللي جاتلك من Firebase بالظبط.

### صلاحيات قاعدة البيانات (مهم للأمان)
من **Realtime Database → Rules** غيّر القواعد لتكون:

```json
{
  "rules": {
    "products": {
      ".read": true,
      ".write": "auth != null"
    },
    "categories": {
      ".read": true,
      ".write": "auth != null"
    },
    "settings": {
      ".read": true,
      ".write": "auth != null"
    },
    "orders": {
      ".read": "auth != null",
      "$orderId": {
        ".write": "!data.exists() || auth != null"
      }
    },
    "customers": {
      ".read": "auth != null",
      ".write": true
    },
    "counters": {
      ".read": true,
      ".write": true
    }
  }
}
```

> **تحديث أمان**: القواعد دي بقت فعليًا آمنة — أي حد يفتح أدوات المطور مش هيقدر يعدّل المنتجات أو يشوف الأوردرات/العملاء غير لو عامل تسجيل دخول حقيقي (خطوة 1.5 تحت). قراءة المنتجات/الأقسام فقط متاحة للجميع لأن المتجر نفسه محتاج يعرضها.

---

## 1.5) تفعيل تسجيل دخول حقيقي للأدمن (خطوة مهمة للأمان)

قبل كده كلمة مرور لوحة التحكم كانت مجرد حماية شكلية. دلوقتي بقينا نستخدم **Firebase Authentication** الحقيقي، فلازم تعمل حساب مرة واحدة بس:

1. في Firebase Console، من القائمة الجانبية: **Build → Authentication**.
2. دوس **Get started**.
3. من قائمة طرق تسجيل الدخول، فعّل **Email/Password** (اضغط عليها → شغّل المفتاح Enable → Save).
4. روح تبويب **Users** → **Add user**.
5. الإيميل اكتبه بالظبط كده: `admin@sphinxpack.app`
6. كلمة المرور: اختار أي كلمة مرور قوية تحبها (٦ حروف على الأقل) — دي هي كلمة مرور دخولك للوحة التحكم من دلوقتي.
7. احفظ (Add user).

كده خلاص، لما تفتح `admin.html` هتدخل بنفس كلمة المرور دي، وتقدر تغيّرها في أي وقت من صفحة الإعدادات جوه لوحة التحكم.

---

## 2) رفع الموقع على GitHub Pages

1. اعمل حساب على **github.com** لو مفيش عندك.
2. اعمل **مستودع جديد (New repository)** باسم مثلاً `sphinxpack`.
3. ارفع كل ملفات المجلد ده (`index.html`, `category.html`, `cart.html`, `admin.html`, `README.md`, ومجلد `assets` بالكامل) إلى المستودع:
   - إما بالسحب والإفلات من صفحة GitHub مباشرة (Add file → Upload files)،
   - أو باستخدام Git من جهازك.
4. من إعدادات المستودع: **Settings → Pages**.
   - في **Source** اختر **Deploy from a branch**.
   - اختر البرانش `main` والمجلد `/ (root)`.
   - احفظ.
5. بعد دقيقة أو اتنين، هيديك GitHub رابط الموقع شكله:
   `https://username.github.io/sphinxpack/`

---

## 3) استخدام لوحة الأدمن

- الرابط: `https://username.github.io/sphinxpack/admin.html`
- كلمة المرور: اللي اخترتها في خطوة 1.5 لما عملت حساب الأدمن.
- تقدر منها:
  - إضافة منتج (اسم، قسم، كمية، سعر، صورة، وباركود — تقدر تمسح الباركود بكاميرا الموبايل بدل ما تكتبه يدوي).
  - تعديل أو حذف أي منتج.
  - متابعة الأوردرات الجديدة والمكتملة، وعدد أوردرات الشهر، وحذف أي أوردر.
  - تأكيد استلام كل أوردر بعد التسليم.
  - متابعة وحذف العملاء.
  - تغيير رقم التواصل وروابط السوشيال ميديا وكلمة المرور من صفحة الإعدادات.
- **سيب صفحة الأدمن مفتوحة على جهازك/موبايلك** عشان تسمع صوت التنبيه أول ما يوصل أوردر جديد (الصوت مبني في المتصفح، فمحتاج الصفحة تكون مفتوحة فعلاً).
- أول مرة هيطلب من المتصفح صلاحية الكاميرا عشان خاصية مسح الباركود — اضغط "سماح/Allow".

---

## 4) إزاي تضيف/تغيّر الأقسام أو رقم الواتساب

- رقم الواتساب: في ملف `assets/shop.js` أول سطر فيه `WHATSAPP_NUMBER`.
- الأقسام: في نفس الملف `assets/shop.js`، مصفوفة `CATEGORIES` — تقدر تغيّر الأسماء أو تضيف قسم جديد بنفس الشكل.

---

## 5) ملاحظات مهمة

- الصور بتتخزن كـ base64 جوه قاعدة البيانات مباشرة (بعد ضغطها تلقائيًا) — ده أبسط حل للبداية، لكن لو الكتالوج كبر جدًا (مئات المنتجات بصور كتير) يفضل الترقية لاستخدام **Firebase Storage** بدل تخزين الصور في الـ Database — قولّي لو حبيت أساعدك تعمل الخطوة دي لاحقًا.
- كل حاجة في الموقع تتحدث لحظيًا (real-time) بين المتجر ولوحة الأدمن من غير ما حد يعمل تحديث للصفحة.
- خطة Firebase المجانية (Spark) هتكفي متجر صغير/متوسط بدون أي تكلفة.
